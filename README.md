# Mixed-Integer Motion Planning for Moving-Target Traveling Salesman Problems with Dynamic Detection Range

This repository contains the implementation accompanying the paper:

**Mixed-Integer Motion Planning for Moving-Target Traveling Salesman Problems with Dynamic Detection Range**

The code provides the implementation of the mixed-integer conic program formulations for three variants of the Moving-Target Traveling Salesman Problem:

- **DR-MT-TSP**: Dynamic Range Moving-Target Traveling Salesman Problem
- **CE-MT-TSP**: Close-Enough Moving-Target Traveling Salesman Problem
- **MT-TSP**: Moving-Target Traveling Salesman Problem

For each problem, both a **big-M based formulation** and a **Graph of Convex Sets (GCS) based formulation** are provided.

## Requirements

The implementation was developed with:

- Python 3.12.6
- Gurobi 12.0.3
- NumPy
- Matplotlib
- Pillow

A valid Gurobi license is required.

Install the required Python packages with:

```bash
pip install gurobipy numpy matplotlib pillow
```

## Toy Examples

Each problem includes one toy instance with 5 targets specified directly at the beginning of the corresponding scripts.

There are three toy instances (one for each problem) in total.

For each problem, the big-M and GCS scripts use the same toy instance, allowing the two formulations to be directly compared.

## Usage

Each script can be run independently.

For example:

```bash
python dr_mttsp_big_m.py
python dr_mttsp_gcs.py
```

Similarly:

```bash
python ce_mttsp_big_m.py
python ce_mttsp_gcs.py

python mttsp_big_m.py
python mttsp_gcs.py
```

Each script constructs the corresponding optimization model, solves it using Gurobi, prints the solution information, and generates a visualization.

Generated visualization files are saved in:

```text
Visualization/
```

The directory is created automatically if it does not already exist.

## DR-MT-TSP

The DR-MT-TSP considers a robot moving in a 3D workspace while visiting moving targets on the ground.

The robot is equipped with a downward-facing sensor whose detection range depends on its altitude. Each target must remain within the sensor detection range continuously for at least the required minimum monitoring duration.

The corresponding implementations are:

```text
dr_mttsp_big_m.py
dr_mttsp_gcs.py
```

The default objective minimizes the inter-target travel distance.

The scripts also include a commented alternative objective that additionally considers the distance traveled during target monitoring, as discussed in Sec. 5.1.5 of the paper.

---

## CE-MT-TSP

The CE-MT-TSP is a 2D special case of the DR-MT-TSP with a fixed circular detection range.

The corresponding implementations are:

```text
ce_mttsp_big_m.py
ce_mttsp_gcs.py
```

Each target must remain within the fixed close-enough range continuously for the required minimum monitoring duration.

The scripts also include the alternative objective that includes the monitoring distance.

---

## MT-TSP

The MT-TSP is the special case without a monitoring requirement or close-enough detection range.

The robot visits each moving target at a single time instant and returns to the depot.

The corresponding implementations are:

```text
mttsp_big_m.py
mttsp_gcs.py
```
